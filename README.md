# AgroConnect

AgroConnect is a modern agriculture platform designed to help farmers, buyers, and agri-service providers connect in one intelligent ecosystem. The app brings together farm management, equipment access, marketplace listings, financial support information, and local agricultural resources in a single streamlined experience.

# Deployed Link 
https://agrico-sooty.vercel.app/

## Why AgroConnect?

Agriculture today needs better access to tools, information, and financial opportunities. AgroConnect helps farmers:

- discover government schemes and subsidies
- browse and compare agricultural equipment
- manage expenses and borrowing needs
- track carbon footprint and sustainability insights
- connect with local agri-market information and resources
- access a community-driven agricultural forum

## Key Features

- Farmer dashboard with actionable insights
- Equipment marketplace and rental management
- Lending and financial support overview
- Expense tracking and cost monitoring
- Carbon footprint calculator
- Farmers' schemes and policy information
- Forum and community discussions
- Responsive UI built for mobile and desktop

## Tech Stack

- React + TypeScript
- Vite
- Tailwind CSS
- shadcn/ui components
- Supabase integration
- Node.js backend services

## Project Structure

- `src/` — frontend application code
- `server/` — backend and API services
- `public/` — static assets and images
- `database_schema.sql` — database schema
- `database_data.sql` — sample data

## Getting Started

### Prerequisites

- Node.js 18+
- npm

### Installation

```bash
npm install
```

### Run the app locally

```bash
npm run dev -- --host 0.0.0.0
```

The application will run on:

- http://localhost:8080/

### Start backend services

```bash
npm run backend
```

## Development Notes

This project is built as a full-stack agriculture platform with a frontend interface and supporting backend APIs for data access, equipment management, forum operations, and service-related features.
